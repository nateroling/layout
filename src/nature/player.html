Movement by variant

Measured over every frame step: how far each file that exists in both frames moved, in file widths (the square root of the layout’s area per file), with the root pinned where the layout puts it. Moves is the mean per file per step; jumps the share of moves over two widths; worst step the largest mean over one step, which is when a big subtree shifted; u²/file is the bounding box per file, so lower is denser.

Frames are evenly spaced commits on the first-parent history; the variations that remember only see those frames. Folders are matched by path, so a renamed folder counts as new. Files keep their identity (and colour) through renames, so moves glide instead of popping. Folder colours come from the final tree. Source: src/nature/, regenerate with node bin/nature-anim.ts.
